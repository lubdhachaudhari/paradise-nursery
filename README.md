# Paradise Nursery

## Project Name

Paradise Nursery - Online Plant Shop

## Description

Paradise Nursery is an online plant shop application where users can browse different plants, add plants to their shopping cart, update quantities, remove products, and view the total cart amount.

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite

## Features

- Paradise Nursery landing page
- About Us section
- Plant product listing
- Add to Cart functionality
- Shopping Cart
- Increase and decrease product quantity
- Remove products from cart
- Automatic cart total calculation
